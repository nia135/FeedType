# FeedType: Feedback Focus and Pedagogical Adaptivity Corpus

FeedType evaluates whether LLM-generated feedback on student writing reflects the focus and adaptivity of expert teacher feedback. Introduced in our paper *"Evaluating Feedback Focus and Pedagogical Adaptivity in LLM-Generated Feedback on Student Writing."*

---

## Dataset Summary

FeedType extends the [SEFORA corpus](https://arxiv.org/abs/2607.00274) by labeling its teacher feedback with feedback focus types and generating LLM feedback on the same paragraphs for comparison. It contains 1,793 paragraph–feedback pairs across three university writing courses: Composition, ESL Composition, and Introduction to Fiction. Feedback comes from expert teachers as well as six LLMs — Mistral-7B, Mistral-24B, LLaMA-3.1 8B, Qwen2.5-70B, Gemini 2 Flash, and LearnLM — each prompted under three strategies: zero-shot(Prompt 1), zero-shot with categories(Prompt 2), and few-shot with categories(Prompt 3). All feedback is annotated by feedback focus type: Task Constraints, Concepts, Elaboration, Clarification, Mistakes, Praise, or Other.

The dataset is organized into a `Models/` folder, containing feedback generated by LLMs, with one subfolder per model, and a `Teacher/` folder, containing feedback from expert instructors. Both are split into two batches, corresponding to different semesters as categorized in SEFORA; for each semester, we selected a specific course and class from the SEFORA corpus. Each essay draft is one JSON file, containing a list of paragraphs. Each paragraph has its text plus an `annotations` list: teacher comments carry a `comment` and `teacher_category`, and model comments carry a `model_comment` and `model_category` — both labeled with one of the seven feedback focus types.

---

## Annotation Reliability

- **Gemini 2.0 Flash** was validated as an automatic annotator (κ = 0.78 with humans, passing the Alt-Test) and used to scale annotation across the full corpus.
- Only paragraphs that received exactly one teacher comment are included in the focus-type analysis.
